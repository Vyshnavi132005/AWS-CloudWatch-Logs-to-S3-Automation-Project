# Screenshots

Place reviewed and redacted project screenshots in this folder.

Suggested screenshots:

1. EC2 / Nginx running
2. CloudWatch Agent configuration
3. CloudWatch Log Group and Log Stream
4. Manual CloudWatch → S3 export
5. S3 archived log object
6. Lambda function
7. Lambda execution/result
8. EventBridge Scheduler
9. EventBridge schedule configuration
10. Final S3 output

## Before uploading

Remove or blur:

- AWS account IDs
- Public IP addresses where unnecessary
- Private IP addresses where unnecessary
- Access keys
- Secrets
- Passwords
- Sensitive ARNs or identifiers
